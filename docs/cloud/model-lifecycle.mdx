---
title: Cloud model lifecycle
description: Review upcoming and past Ollama Cloud model retirements and recommended replacements.
---

Ollama occasionally deprecates and retires older Cloud models as newer models become available. Tools and applications that depend on a retired model must be updated to use another model.

Impacted users are notified before a model is retired. Cloud model retirement does not affect local models.

## Upcoming retirements

No Cloud model retirements are currently scheduled.
