## Choose where models run

Cloud and local models use the same Ollama tools and API shapes. The main difference is where inference runs.

<CardGroup cols={2}>
  <Card title="Cloud" icon="cloud" href="/cloud">
    Run larger models without managing local compute, either from Ollama or through the Cloud API.
  </Card>

  <Card title="Local" icon="hard-drive" href="/local">
    Install Ollama and run models on macOS, Windows, Linux, or Docker.
  </Card>
</CardGroup>

Browse the [model library](https://ollama.com/search) for coding, vision, embeddings, and reasoning models.

## What you can build

Ollama supports [streaming](/guide/capabilities/streaming), [tool calling](/guide/capabilities/tool-calling), [structured outputs](/guide/capabilities/structured-outputs), [decision models](/guide/capabilities/decision), [vision](/guide/capabilities/vision), [embeddings](/guide/capabilities/embeddings), [thinking](/guide/capabilities/thinking), and [web search](/guide/capabilities/web-search).
