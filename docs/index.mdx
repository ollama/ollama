Build with open models in Ollama Cloud or on your own hardware.

Follow the [quickstart](/guide/quickstart), then choose the environment that matches your needs.

## Choose where models run

Cloud and local models use the same Ollama tools and API shapes. The main difference is where inference runs.

<CardGroup cols={2}>
  <Card title="Cloud" icon="cloud" href="/cloud">
    Run larger models without managing local compute, either from Ollama or through the Cloud API.
  </Card>

  <Card title="Local" icon="laptop" href="/local">
    Install Ollama and run models on macOS, Windows, Linux, or Docker.
  </Card>
</CardGroup>

## What you can build

Ollama supports [streaming](/guide/capabilities/streaming), [tool calling](/guide/capabilities/tool-calling), [structured outputs](/guide/capabilities/structured-outputs), [vision](/guide/capabilities/vision), [embeddings](/guide/capabilities/embeddings), [thinking](/guide/capabilities/thinking), and [web search](/guide/capabilities/web-search).
