[OpenCode](https://opencode.ai) is an open-source coding agent that runs in your terminal, reads your project, edits files, and runs commands.

OpenCode can use local and cloud models from Ollama.

## Get started

Start Ollama, then run the launcher.

```shell
ollama launch opencode
```

The launcher installs OpenCode 2 and the Ollama plugin if needed, then opens OpenCode. If you already have OpenCode installed, use version 2.4.1 or newer in the 2.x series.

To start a new chat with a specific model, pass `--model`.

```shell
ollama launch opencode --model qwen3.8:27b
```

## Manual setup

Install [OpenCode 2](https://opencode.ai/docs/#cli), then run `opencode`. With Ollama running, open `/models` to choose a local model. For a direct Ollama Cloud connection, choose **Ollama Cloud** in `/connect`.

Use `--config` for setup only.

```shell
ollama launch opencode --config
```

For a custom Ollama host, set `providers.ollama.settings.baseURL` in your [OpenCode provider settings](https://opencode.ai/docs/providers/#ollama).
