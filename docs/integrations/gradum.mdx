[Gradum](https://plugins.jetbrains.com/plugin/34788-gradum) is an open-source AI coding agent for IntelliJ IDEA built around Ollama from day one: it was the first provider Gradum ever supported and remains the primary target. Skills are plain Kotlin source files, every destructive command waits for approval, and the agent talks to the native Ollama API with full tool-calling support, entirely on your machine.

Ollama is not an adapter for Gradum. It is the native tongue.

## Get started

1. Install Gradum from the JetBrains Marketplace:

```shell
Settings > Plugins > Marketplace > search "Gradum" > Install in your IDE
```

Direct link: [plugins.jetbrains.com/plugin/34788-gradum](https://plugins.jetbrains.com/plugin/34788-gradum)

2. Pull a tool-capable model:

```shell
ollama pull qwen3.5:9b
```

3. Open the Gradum tool window and pick a model. Gradum discovers your installed models automatically; `http://localhost:11434` is the default and usually needs no change.

## Remote Ollama

Point Gradum at any Ollama host by setting the endpoint to `http://<host>:11434`. No API key, no extra setup - a GPU box on your LAN behaves exactly like localhost.
