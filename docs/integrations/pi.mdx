[Pi](https://pi.dev/) is a terminal coding agent. Use the Ollama plugin to connect Pi to local models and Ollama's cloud.

## Quick setup

```shell
ollama launch pi
```

Ollama installs Pi and the plugin if needed, then opens Pi. It keeps the version of Pi you already have.

Use Pi 1.5.2 or newer. If you installed an older version with npm, update it before launching.

```shell
npm install -g @earendil-works/pi-coding-agent@latest
```

In Pi, run `/model` to choose your default model.

For direct access to Ollama's cloud, run `/login ollama` and enter an [Ollama API key](https://ollama.com/settings/keys) before choosing a `cloud/` model. See [manual setup](#manual-setup) to install the plugin yourself.

## Run directly with a model

After saving your Ollama API key with `/login ollama`, start a session with DeepSeek's V4.1 Flash.

```shell
ollama launch pi --model cloud/deepseek-v4.1-flash
```

`--model` selects a model for one session. Pi keeps your saved default. Browse [cloud models](https://ollama.com/search?c=cloud).

## Extensions

Pi includes `read`, `write`, `edit`, and `bash`. Add tools and skills with [Pi packages](https://pi.dev/packages) from npm or Git. Run an installed skill with `/skill:name`.

### Web search

The Ollama plugin adds web search and fetch. In Pi, run `/web on` to enable them for the session. Run `/web off` to turn them off.

The tools use the Ollama API key from `/login ollama` or `OLLAMA_API_KEY`. Without a key, they use your Ollama server. Sign in on that server with `ollama signin`.

### Autoresearch with `pi-autoresearch`

[pi-autoresearch](https://github.com/davebcn87/pi-autoresearch) runs experiments to improve a metric, such as test runtime or bundle size. It follows Andrej Karpathy's autoresearch loop.

```shell
pi install npm:pi-autoresearch
```

Give Pi a goal.

```text
/autoresearch optimize unit test runtime
```

The extension measures each change, commits improvements, and reverts regressions. The dashboard tracks results. Run `/autoresearch finalize` to group kept changes into branches for review.

## Manual setup

### Install Pi and the Ollama plugin

[Install or update Pi](https://docs.pi.dev/latest/quickstart) to version 1.5.2 or newer, then install the Ollama plugin.

```shell
pi install https://github.com/ollama/pi-ollama
```

### Cloud models

Start Pi.

```shell
pi
```

Run `/login ollama` in Pi and enter your API key. Use `/model` to choose a `cloud/` model. Pi connects directly to Ollama's cloud, so you can use it without a local server.

### Local models

Install and start [Ollama](https://ollama.com/download). Download a model, such as Google DeepMind's Gemma 4 12B, and start Pi.

```shell
ollama pull gemma4:12b
pi
```

Run `/model` in Pi and choose a model labeled **local**. The default local server works without an API key.

Set `OLLAMA_HOST` to choose the server Pi connects to.

```shell
OLLAMA_HOST=http://localhost:11434 pi
```

To use cloud models through your Ollama server, run `ollama signin` on the server. In Pi, choose a model labeled **Cloud via server**.
