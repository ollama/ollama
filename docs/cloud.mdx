Ollama Cloud runs larger models without requiring a powerful GPU. Cloud models support the same capabilities as local models, but inference runs on Ollama's cloud service.

## Choose how to connect

<CardGroup cols={2}>
  <Card title="Use Cloud models from Ollama" icon="terminal" href="/cloud/models">
    Use the Ollama CLI, Python or JavaScript library, or your local Ollama API. Cloud model names use the `:cloud` suffix.
  </Card>

  <Card title="Call the Cloud API directly" icon="cloud" href="/cloud/api">
    Send authenticated requests to `https://ollama.com/api` without installing Ollama.
  </Card>
</CardGroup>

Both options require an Ollama account. Browse the available models in the [cloud model library](https://ollama.com/search?c=cloud).

## Cloud models

Follow [Use Cloud models from Ollama](/cloud/models) to run a `:cloud` model from the CLI, official libraries, or the local Ollama API.

## Cloud API access

Follow the [Cloud API guide](/cloud/api) to call `https://ollama.com/api` directly with an API key.

## Local only

Use [Local](/local) when you want inference to run on hardware you control. Ollama can also run in [local-only mode](/faq#how-do-i-disable-ollama-cloud-features) with Cloud features disabled.

## Retirements

Cloud models may be deprecated as newer models become available. See [Cloud model lifecycle](/cloud/model-lifecycle) for upcoming and past retirements.

For questions about Cloud accounts, privacy, authentication, and requests, see the [Cloud FAQ](/cloud/faq).
