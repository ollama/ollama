Run larger models in Ollama's cloud without requiring a powerful GPU. Cloud models support the same capabilities as local models, but inference runs on Ollama's cloud service.

## Choose how to connect

  <Card title="Creating an API key" icon="key" href="/cloud/api">

  </Card>

Both connection methods require an Ollama account. Browse the available models in the [cloud model library](https://ollama.com/search?c=cloud).

## Use only local models

To keep inference on your own hardware, follow [Run a model locally](/quickstart#run-a-model-locally). You can also [disable cloud features](/faq#how-do-i-disable-ollama-cloud-features).

## Retirements

Cloud models may be deprecated as newer models become available. See [Cloud model lifecycle](/cloud/model-lifecycle) for upcoming and past retirements.

## Data handling

Ollama processes cloud prompts and responses to answer your requests. We do not use them to train models. Read the [Privacy Policy](https://ollama.com/privacy) for details or see the [Cloud FAQ](/cloud/faq).
