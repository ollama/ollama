## Run a local model

After installation, start a model from the terminal:

```shell
ollama run gemma4
```

Ollama also serves its local API at `http://localhost:11434/api` by default.

```shell
curl http://localhost:11434/api/chat -d '{
  "model": "gemma4",
  "messages": [{"role": "user", "content": "Why is the sky blue?"}],
  "stream": false
}'
```

## Configure your environment

- Use the [CLI reference](/local/cli) to run, download, copy, and remove models.
- Adjust the [context length](/local/context-length) for agents and other long-context workloads.
- Review [hardware support](/local/gpu) for GPU compatibility and acceleration.
- [Import a model](/local/import) or create a customized model with a [Modelfile](/local/modelfile).
- Use [local-only mode](/local/faq#how-do-i-disable-ollama-cloud-features) to disable Ollama Cloud features.

For failures, start with [Troubleshooting](/local/troubleshooting).
