Use Ollama's API to run and interact with models.

## Get started

Choose how the request reaches the model:

| Access path | Model runs on | Base URL | Authentication and model name |
| --- | --- | --- | --- |
| [Local model](/local) | Your hardware | `http://localhost:11434/api` | None by default; use the local model name |
| [Cloud model through Ollama](/cloud/models) | Ollama Cloud | `http://localhost:11434/api` | Run `ollama signin`; use a model name ending in `:cloud` |
| [Direct Cloud API](/cloud/api) | Ollama Cloud | `https://ollama.com/api` | Send an Ollama API key; use the Cloud API model name |

Request bodies have the same shape for shared endpoints. The host, authentication, and model name depend on the access path.

## Local API

After you [install Ollama](/local), its API is served by default at:

```
http://localhost:11434/api
```

## Cloud API

For direct access to models hosted on Ollama Cloud, use:

```
https://ollama.com/api
```

Cloud API requests require an API key. See [Cloud API authentication](/cloud/api#authentication).

## Example request

Once Ollama is running locally, its API is automatically available and can be accessed with `curl`:

```shell
curl http://localhost:11434/api/generate -d '{
  "model": "gemma4",
  "prompt": "Why is the sky blue?"
}'
```

## Libraries

Ollama has official libraries for Python and JavaScript:

- [Python](https://github.com/ollama/ollama-python)
- [JavaScript](https://github.com/ollama/ollama-js)

Several community-maintained libraries are available for Ollama. For a full list, see the [Ollama GitHub repository](https://github.com/ollama/ollama?tab=readme-ov-file#libraries--sdks).

## Versioning

Ollama's API isn't strictly versioned, but the API is expected to be stable and backwards compatible. Deprecations are rare and will be announced in the [release notes](https://github.com/ollama/ollama/releases).
