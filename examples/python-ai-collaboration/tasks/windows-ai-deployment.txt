請撰寫一個強健的 PowerShell 部署腳本，用於初始化 AI 執行環境，並提供簡潔的使用說明。腳本必須具備以下功能：

1. 硬體環境驗證
   - 自動檢測系統是否安裝 NVIDIA RTX 5070 Ti 顯示卡。
   - 使用可用的 NVIDIA 工具確認 GPU 驅動與加速能力；若工具不存在，提供明確且可操作的錯誤訊息。
   - 輸出 CPU 型號與 RAM 總容量。
   - 找不到指定 GPU 或無法確認 GPU 加速時，必須以非零結束碼停止。

2. 動態定位外接 SSD
   - 使用 Get-Volume 或 Windows 儲存體 Cmdlet 尋找檔案系統標籤完全等於「Crucial X9」的磁碟區。
   - 反查實體磁碟，確認 FriendlyName 完全等於「Micron CT1000X9SSD9」且 BusType 是 USB。
   - 必須驗證磁碟區具有唯一且有效的磁碟機代號。
   - 找不到磁碟區、找到多個同名磁碟區，或磁碟區無磁碟機代號時，必須報錯並停止。
   - 所有後續路徑都應透過 Join-Path 從該磁碟機根目錄建立，不可手動串接未驗證的路徑。

3. GitHub 專案精準部署
   - 不可下載 ZIP。
   - 在外接 SSD 中 clone https://github.com/AKB0700/ollama.git。
   - 分支名稱必須由必填參數傳入，不可在腳本中猜測「最新修改」位於哪個分支。
   - 新 clone 時直接取得指定分支；目標目錄已存在時，只能在確認它是相同 remote 的 Git repository 後 fetch 並切換分支，不可覆寫或刪除既有資料。
   - 檢查 Git 是否存在、每個外部命令的結束碼，以及工作目錄是否有未提交修改；任何可能破壞使用者資料的情況都必須停止並說明原因。
   - 最後輸出實際使用的磁碟機、repository 路徑、分支名稱與 commit SHA。

請以 Windows PowerShell 5.1 相容語法實作，啟用嚴格模式與停止式錯誤處理，不得要求重新開機，也不得自動執行需要系統重新啟動的操作。
